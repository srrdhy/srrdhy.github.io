SDF-PINN Signed Distance Function

Created2025-06-17|Updated2026-11-04|PINN
|Post Views:

SDF, the signed distance function, is a function that expresses the distance between an object’s surface and any point in space.

  • For points inside the object, the SDF value is positive;
  • For points outside the object, the SDF value is negative;
  • For points on the object’s surface, the SDF value is zero.
    The SDF describes an object’s geometry and boundary precisely, which makes it convenient to handle complex geometric problems.

For example, for the circular domain $\Omega = \{ \mathbf{x} : x^2 + y^2 < 1 \}$, the $SDF$ function $\phi(x)$ is defined as the shortest distance from a point $x$ to the boundary $\partial \Omega$:
$$\phi(x) = 1 - \sqrt{x^2 + y^2}$$

  • $\phi(\mathbf{x}) = 0$, when $\mathbf{x} \in \partial \Omega$;
  • $\phi(\mathbf{x}) > 0$, when $\mathbf{x} \in \Omega$ (inside);
  • $\phi(\mathbf{x}) < 0$, when $\mathbf{x} \notin \Omega$ (outside).

In a PINN, using the SDF to assign weights to the loss terms prevents conflicts at the boundary: for points near the boundary the weight of the physics loss is very low, while the weight of the boundary loss is high.

For instance, in the complex polygonal computational domain shown below, interior points are positive (red) and exterior points are negative (blue); the value is numerically the shortest distance from the point to the polygon boundary, so exterior points get bluer the farther they are from the boundary and interior points get redder the deeper they lie inside, while boundary points are green, with a value of 0.
