Understanding the Fourier neural operator (FNO)

Created2025-06-10|Updated2026-11-04
|Post Views:

FNO is a method for solving PDEs by means of “operator learning”, following PINN; its full name is Fourier Neural Operator.
Paper: https://arxiv.org/pdf/2010.08895
Code reference: https://github.com/lu-group/deeponet-fno/tree/main?tab=readme-ov-file

The figure above shows the architecture of FNO. We start from the simplest one-dimensional transient Burgers’ equation, whose governing equation is:
$$\frac{\partial u}{\partial t}+u\frac{\partial u}{\partial x}=\nu\frac{\partial^2u}{\partial x^2},\quad x\in(0,1),t\in(0,1],$$
with periodic boundary conditions, and we take $\nu=0.1$.

Operator learning here means learning the solution corresponding to a set of initial conditions. The input of the neural network is $u(x,t=0)=u_o(x)$, and the output is $u=u(x,t=1)$, so the operator $G$ learned by the neural network can be expressed as:
$$G:u_0(x)\mapsto u(x,t=1)$$

Data preparation

The training dataset was generated with MATLAB, as shown below:

$u_0(x)$ and $u(x,t=1)$ are the $a$ and $u$ here; $(2048x8192)$ means there are 2048 different initial conditions, each with 8192 values of $x$. Uniform sampling is used here, i.e. x = linspace(0,1,8192).

The figure above shows the values of $u(x,t)$ at time 0 on the positions $(0,1)$; note that these are not the values of $x$, which is why they can be either positive or negative.

The generation of the dataset may have an important influence on the final result and on the generalization performance of the network. A random sampling method is used here, whose core idea is the Gaussian random field; we will not elaborate on it here.

Loading and processing the data

Read data from the .mat file -> downsample -> split into training set and test set

x_data and y_data contain only the values of $u(x,t)$: 2048 sets of initial conditions, of which 1000 are taken as the training set and 200 as the test set. Below, the data of the grid positions $x$ is generated and concatenated with $u$, finally forming a dataset of shape (1000, 128, 2) that serves as the overall input. During training, one batch has shape (batch_size=20, 128, 2), and the two numbers in the last dimension are the value at that position at the initial time and the coordinate of that position, respectively.

grid.repeat(ntrain,1,1) simply repeats along the dimension dim = 0 (the dimension of different samples); put plainly, it makes grid[x, a, b] = grid[y, a, b].

class FNO1d

The actual shape of the neural network input is (20, 128, 2), where the first dimension 20 refers to batch_size=20. Here the dimension lifting of fc0 turns it into (20, 128, 64). This both makes the network independent of the number of grid points and raises the dimension; this step is also an important part of why the FNO input is independent of the grid resolution (the other part is related to taking a fixed number of modes after the Fourier transform).

Raising the dimension has two benefits:

  1. Because the features of shape (128, 2) at the moment are merely a projection of a higher-dimensional function space onto a finite number of dimensions, this length may not be sufficient to represent the mapping from the original function space to another function space (or it cannot be done at the required accuracy). This step therefore expands the feature length to (128, 64), and all subsequent neural network transformations are carried out at this size (in a higher-dimensional space closer to the original function space), which allows more complex transformations to be learned, before the result is finally projected back to a low dimension.

  2. The first dimension 128 is kept unchanged. On the one hand, this makes the network independent of the grid resolution; on the other hand, it also takes the subsequent Fourier transform into account. This first dimension has physical meaning: it is directly tied to position/grid, so applying a Fourier transform along this dimension is a more physically meaningful operation (there is a permute operation later). If we raised the dimension along this axis instead, the original physical meaning would be lost (we would enter a more abstract high-dimensional space; performing a Fourier transform there may be feasible, but it is hard to justify).

This is consistent with the network structure figure shown earlier: a Fourier block consists of one Fourier layer and one bias, where the bias is a 1D convolutional layer whose input and output channels are equal to width=64 and whose kernel size is 1x1. The two are added, and then an activation function is applied.

class SpectralConv1d

The concrete implementation of the Fourier layer is as follows:

The weight self.weights1 has shape (64, 64, 16), where the last dimension is the truncation order 16 of the Fourier transform.

Part of the Fourier layer is in fact like performing a fully connected operation in the frequency domain: no matter how long the input is, after transforming to the frequency domain only the first 16 modes are taken for the transformation and then transformed back, so it is independent of length/grid resolution.

Optimizer

The Adam algorithm is used, and every step_size epochs the learning rate is multiplied by gamma as decay.

utilities

The code introduces three custom functions (classes): MatReader, count_params, and LpLoss, which are briefly introduced here.

The MatReader class is used to read .mat data.

LpLoss is used to compute the $L_p$ norm loss; the $L_2$ loss is adopted here, and a relative error or an absolute error can be chosen.

count_params is used to compute the number of parameters of an arbitrary neural network model — quite an interesting general-purpose function.
