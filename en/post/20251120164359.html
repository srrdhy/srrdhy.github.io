FB-PINN Paper Reading 02 - Basic Principles

Note

In FB-PINN, the problem domain $\Omega \subset \mathbb{R}^d$ is subdivided into $n$ overlapping subdomains $\Omega_i \subset \Omega$. The subdivision can be of any type, regular or irregular, and the overlap can have any width (though overlap between subdomains is essential). For simplicity, we present a regular subdivision (a hyperrectangular partition):

We have the approximate solution:
$$\hat{u}(x;\theta) = \mathcal{C}\left[ \overline{NN}(x;\theta) \right]$$
Here $x \in \Omega \subset \mathbb{R}^d$ is the physical coordinate; $\overline{NN}(x;\theta)$ is the function that combines all subdomain networks; and $\mathcal{C}$ is the constraint operator used to enforce hard boundary conditions.

where:
$$ \overline{NN}(x;\theta) = \sum_{i}^{n} w_i(x) \cdot \text{unnorm} \circ NN_i \circ \text{norm}_i(x) $$
$NN_i(x;\theta_i)$ is an independent neural network placed in each subdomain $\Omega_i$. For each $NN_i$:

  1. Normalize the input with $\text{norm}_i(x)$, mapping the input $x$ into $x \in [-1,1]$
  2. Pass it through the subdomain network $NN_i$
  3. Apply a uniform output “unnormalization” $\text{unnorm}$ to ensure that each subdomain network’s output stays within $[-1,1]$
  4. Apply the window function $w_i(x)$, which confines the network to its subdomain

$NN_i$ can be any neural network; for simplicity we consider only MLPs.

The value of $w_i(x)$ is essentially 0 outside the subdomain and greater than 0 inside it. For a regular hyperrectangular partition (intervals in 1D, a collection of small rectangles in 2D), we use the following window function:
$$ w_i(x) = \prod_{j}^{d} \phi\left( \frac{x^j - a_i^j}{\sigma_i^j} \right) \phi\left( \frac{b_i^j - x^j}{\sigma_i^j} \right) $$
Here $j$ indexes each dimension of the input vector, $a_i^j$ and $b_i^j$ are the left and right overlap boundaries in each dimension ($a_i^j < b_i^j$), $\phi$ is the sigmoid function, $\phi(x) = \frac{1}{1+e^{-x}}$, and $\sigma_i^j$ is a parameter controlling the slope, so that the window function is nearly 0 outside the overlap region.

Finally, FB-PINN uses an unconstrained loss function:
$$ \mathcal{L}(\theta) = \mathcal{L}_p(\theta) = \frac{1}{N_p} \sum_{i}^{N_p} \left\| \mathcal{D}\left[ \hat{u}(x_i;\theta); \lambda \right] - f(x_i) \right\|^2 $$

Experiments

To put the above method into practice, we again consider the 1D example from before:
$$\frac{du}{dx} = \cos(\omega x),$$ $$u(0) = 0,$$
This equation has the exact solution:
$$u(x) = \frac{1}{\omega} \sin(\omega x)$$
We assume the solution has the form:
$$\hat{u}(x; \theta) = \tanh(\omega x) NN(x; \theta)$$
Here $\tanh(\omega x)$ is the constraint operator $\mathcal{C}$.

In the low-frequency case, the domain $x \in [-2\pi, 2\pi]$ is divided into $n=5$ overlapping subdomains, with an overlap width of 1.3 between adjacent subdomains. To obtain 5 subdomains, we first divide the computational domain into 5 equidistant points:

The total length of a subdomain consists of the non-overlapping width plus the overlap width.

With the total subdomain half-width in hand, building 5 subdomains is simply a matter of extending each of the 5 equidistant points by one total half-width to the left and right. This gives the left and right boundary coordinates of each subdomain:
