3. Implementing the Fast Fourier Transform (FFT) in Python

Created2025-06-09|Updated2026-11-04
|Post Views:

The solution that speeds up the Fourier transform is called the Cooley-Tukey algorithm, which relies on 2 key improvements.

Improvement 1 — The Divide-and-Conquer Method

The DFT equation is:
$$X[k]=\sum_{n=0}^{N-1}x[n]e^{-i2\pi\frac{k}{N}n}$$
where $k$ ranges from $0$ to $N-1$

Let us split it into 2 halves, the even indices $n=2m$ and the odd indices $n=2m+1$
$$X_k = \sum_{m=0}^{N/2 - 1} x_{2m} e^{-\frac{2\pi i}{N} (2m) k} + \sum_{m=0}^{N/2 - 1} x_{2m + 1} e^{-\frac{2\pi i}{N} (2m + 1) k}=E_k+e^{-\frac{2\pi i}{N}}O_k$$
where $k$ ranges from $0$ to $\frac{N}{2}-1$

Therefore, the original x vector of size $N$ is split into $E_k$ and $O_k$, each of size $N/2$.

Since a vector of size $N$ requires $N^2$ computations, each halved vector now requires $(N^2)/4$ computations. This means that obtaining the Fourier vector of the original size requires only $(N^2)/2$ computations.

We continue this process until we obtain vectors of size 1. Note that, because we split the input array into 2 halves, $N$ must be a multiple of 2. If it is not, the array can be extended by padding the end with zeros.

As a result, the time complexity changes from $O(n^2)$ to $O(nlogn)$, where the base is 2.

Improvement 2 — Periodicity of Sinusoidal Functions

From https://en.wikipedia.org/wiki/Cooley%E2%80%93Tukey_FFT_algorithm

In summary, if $N=2000$, we only need to compute the Fourier vector for the first 1000 values and reuse it for the lower half.
